# Concept

## Point of departure

Luis Küffner's *Materialität am Übergang* examines a shift from a
hylomorphic model of composition toward a process-based one. In the first
model, form is imposed on supposedly passive material. In the second, a work
emerges through the interaction of material, form, technology, environment,
and time.

This project takes that distinction as a practical software-art problem:
can the computer stop being a neutral playback device and become one of the
forces from which the music emerges?

## The first experiment

The laptop reports its own changing conditions:

- CPU activity
- memory use
- normalized system load
- number of running processes
- battery level, when available
- timing instability in the telemetry process

These values do not select notes from a fixed melody. They change a field of
behaviours: population, spectral brightness, event density, harmonic tension,
drift, and pulse.

The first prototype also contains a limited feedback loop. More available CPU
headroom permits more sound-producing voices. Those voices consume resources
and become part of the next CPU measurement. When the machine grows busy, the
population contracts. The sounding result is therefore coupled to the
conditions of its own production.

This is intentionally a small and safe loop. It is bounded to six voices and
uses smooth envelopes so that adaptation does not become an attempt to crash
the host computer.

## What this is not

It is not a claim that a CPU meter possesses agency, nor that any changing
mapping automatically realizes Simondon's philosophy. Version 0.1 is a
technical and musical probe: a reproducible way to listen to a computational
environment while allowing that environment to constrain the sounding form.

## Next experiment

The next study will compare the same recorded telemetry in two modes:

1. **Imposed Form** — stable one-to-one mappings and a predetermined form.
2. **Co-Individuation** — adaptive relations, hysteresis, and feedback.

Keeping the input data identical will make the compositional difference
audible rather than merely theoretical.
